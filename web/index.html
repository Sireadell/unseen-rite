An open-model repair test

Can an open AI model repair a shop chatbot that has been tricked, and prove the fix on questions it never saw?

We took a shop helper built the quick way, showed it fell for hidden instructions and false claims, and let an open model (Gemma) rewrite it. Then we tested the fix on an exam the repairing model never saw, drawn by a public random number after the fix was frozen.

-attacks that fooled the helper as built (out of 12, exam average)
-attacks that fooled the helper after the open model repaired it
-real customers still helped, out of 8, before and after

Exam: 20 questions the repairing model never saw. Each run 3 times.

This is a controlled test of one claim: an open model can repair a tricked agent, and the repair holds on attacks it never saw. Method, data and every run are public at github.com/Sireadell/unseen-rite. Tested across three attack types on two agents, with the exam drawn after the fix was frozen.
